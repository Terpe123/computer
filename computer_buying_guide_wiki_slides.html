01 / LEARNING PATH

買電腦，第一步不是挑型號

同一台電腦不一定適合每個人。選購的起點應該是用途、使用環境與預算，而不是先看某個零件的型號。

01

確認需求

平常做什麼？需要攜帶嗎？預算包含哪些設備？

02

理解規格

認識 RAM、SSD、CPU、GPU 與軟體需求。

03

查核再購買

核對精確型號、相容性、實測、保固與總成本。

本簡報的核心原則：最低需求只是門檻，不等於流暢使用保證；規格表也不能取代同條件實測。

來源：S01、S02；教學流程為 Wiki 整理
02 / START WITH NEEDS

W01｜先把需求寫清楚

在比較任何商品之前，先回答以下問題。答案越具體，後續越容易排除不適合的選項。

問題可以怎麼寫為什麼重要
主要用途文書、上課、遊戲、剪輯、3D 創作決定需要優先查哪些規格
指定軟體／遊戲完整名稱，必要時加版本不同軟體需求可能不同
攜帶需求每天攜帶？可接受多重？影響筆電或桌機的選擇
總預算金額、幣別、包含項目避免漏算螢幕與周邊
使用目標解析度、畫質、目標 FPS讓效能需求可以被查證

也要記錄既有設備（螢幕、鍵盤、滑鼠）以及對維修、升級與售後服務的偏好。

來源：S01、S02；需求表為教學整理
03 / TOTAL COST

預算要看「總成本」

電腦本體價格不一定等於最後花費。先確認哪些設備已經有，哪些還需要購買。

可能需要納入預算

電腦本體螢幕鍵盤／滑鼠作業系統組裝服務

比較時要問

  • 兩個方案是否包含相同設備？
  • 是否把組裝、服務或其他費用算進去？
  • 報價是否記錄日期、幣別與地區？

避免只比較 CPU 或顯示卡的單一價格。應比較能完成相同任務的整體方案。

來源：S01、S02；總成本整理為教學說明
04 / LAPTOP OR DESKTOP

W02｜筆電還是桌機？

比較面向筆電桌機
攜帶性整合螢幕、鍵盤與電池，適合移動使用通常固定使用，另需螢幕及供電
升級性RAM、SSD 是否可升級依機型而異；CPU、GPU 通常不易更換多數較容易更換零件，但仍需查相容性
客製化主要從廠商提供的配置中選擇通常有較多零件與散熱選擇
效能看具體機型、配置與實測同樣需要看具體配置與實測

不能概括宣稱「筆電與桌機效能一樣」，也不能只憑電腦類型判斷性價比。

來源：S01
05 / DESKTOP PURCHASE

W03｜桌機有三種購買方式

方便優先

預組桌機

廠商事先完成配置與組裝。購買前仍要確認零件型號、擴充空間與售後方案。

配置彈性

客製代組

自行選擇零件，再由店家或業者組裝。要確認組裝費與售後服務內容。

自主性高

自行組裝 DIY

自己購買、組裝與設定，需要投入時間研究、測試與排錯。

常見誤解 1

「組裝桌機」不一定代表自己動手，也可能是請店家代組。

常見誤解 2

DIY 不一定最便宜，也不代表沒有保固；通常要分別確認零件保固與整機服務。

來源：S02
06 / MEMORY BASICS

W04｜RAM 與 SSD 是不同東西

RAM

記憶體：正在工作的桌面

暫時存放正在處理的資料。一般 RAM 在斷電後不保留資料。

容量不足時：多工可能受限，系統反應也可能變慢。

SSD / HDD

儲存裝置：收納櫃

保存作業系統、程式與檔案。正常情況下，斷電後仍會保留資料。

容量不足時：可安裝程式或保存檔案的空間不足。

教學比喻：RAM 像工作桌，SSD 像收納櫃。增加 SSD 容量，不能當成增加同等容量的 RAM。

補充：儲存裝置能在斷電後保留資料，不代表資料永遠不會損壞或遺失。RAM 充足後，再增加容量也不一定能改善目前的效能瓶頸。

來源：S03；Wiki 已排除自動翻譯中容易混淆 RAM 與磁碟空間的操作建議
07 / SOFTWARE REQUIREMENTS

W05｜先看軟體需求，再決定硬體

不同作業系統與應用程式有不同的最低或建議條件。以下數字只代表 Wiki 所整理來源中的特定需求摘要，不是完整配單。

Windows 11

4 GB

Wiki 所列最低 RAM；另有處理器、儲存空間、UEFI、安全開機、TPM 2.0 與圖形支援等條件。

不能因此推薦所有人購買 4 GB RAM 的電腦。

Premiere 27.0

16–32 GB+

Wiki 所列 HD 素材建議 16 GB；4K 及以上建議 32 GB 或以上。Windows on Arm 的最低記憶體另列為 16 GB 共用記憶體。

Premiere 的記憶體資訊只是部分需求，不能省略 CPU、GPU、作業系統與儲存裝置條件。Copilot+ PC 也有額外條件，不是所有 Windows 11 電腦都必須具備。

來源：S04、S05（Premiere 資料依 Wiki 標示版本 27.0、更新日期 2026/11/10）

11 / DESKTOP COMPATIBILITY

W07｜桌機配單要檢查相容性

Wiki 以 MSI MAG B650 TOMAHAWK WIFI 主機板作為規格閱讀案例，僅用來示範如何讀規格，不是購買推薦。

CPU 與主機板

確認 CPU 插槽、精確型號與 BIOS 支援，不要只看系列名稱。

RAM

案例主機板使用 DDR5、4 個插槽；不能搭配 DDR4。標註 OC 不代表所有配置都能達到最高速度。

顯示輸出與 PCIe

HDMI／DisplayPort 輸出要確認 CPU 是否具備內建顯示功能。x16 外觀不代表一定以 x16 運作。

M.2 與共用資源

部分 CPU 可能使特定插槽不可用；案例中 M.2_3 與 PCI_E2 共用頻寬，需讀取註腳。

來源：S07、S08；S08 的 CPU 支援表缺少表頭，因此不據此判定最低 BIOS 版本

13 / LAPTOP CONFIGURATION

W08｜筆電要看完整商品型號

同一系列可能有多種配置。不能把不同商品的 CPU、RAM、SSD 與連接功能拼成一台不存在的筆電。

核心配置

  • 完整商品型號與 CPU
  • RAM 容量、類型、焊接或插槽設計
  • SSD 容量與空插槽

使用體驗

  • 螢幕解析度、亮度、更新率與色域
  • 筆電重量與變壓器重量
  • USB-C 充電與影像功能
  • 保固、價格與供貨

Wiki 中的資料限制

ASUS Vivobook 15 X1504 的多配置欄位對應遺失，因此本版不產生單一型號配單。擴充插槽包含已使用的，不代表仍有空位；42 Wh 也不能直接換算續航時數。

來源：S09
14 / SCENARIO 1

W09｜情境一：文書、視訊、經常攜帶

教學假設案例

需求描述

主要處理文書與視訊，經常需要帶著電腦移動，不玩遊戲。

優先比較方向

先比較一般筆電，因為攜帶性是明確需求。

購買前查核

  • 指定軟體是否支援
  • 實際重量與變壓器重量
  • 鍵盤、連接埠與螢幕
  • 續航測試與保固
  • 總預算是否包含必要周邊

這是需求分析示範，不是特定品牌或型號推薦，也沒有虛構報價或續航測試。

來源：S01、S09；案例為 Wiki 的教學假設
